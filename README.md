# Doorway

## Tech stack

| Layer | Technology |
|---|---|
| Engine | Unity 6000.3.25f1 (Built-in Render Pipeline) |
| Language | C# |
| AR | AR Foundation 6.3.5, ARCore XR Plugin 6.3.5 |
| Input | Unity Input System |
| UI | uGUI 2.0.0 |
| Platform | Android, API 25+, ARM64, IL2CPP, OpenGL ES 3 |
| Location | Android GPS (Unity `Input.location`) |
| Data pipelines | Python 3.12, NumPy, SciPy, OpenCV, Pillow, Shapely, mapbox_earcut |
| Map data | OpenStreetMap (Overpass API) |
